# Site fonts

The site's three fonts, self-hosted so `next build` never fetches anything
from Google Fonts:

- [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono), weights 400 to 700 (variable)
- [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono), weights 400 to 700
- [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans), weights 300 to 700 (variable)

They used to load through `next/font/google`, which downloads the files during
the build. Builds failed whenever Google answered with extensionless
`/l/font?kit=` URLs ([vercel/next.js#99114](https://github.com/vercel/next.js/issues/99114)).

Everything in this folder except this README is generated by
`scripts/fetch-fonts.mjs`. Don't edit it by hand. To change a weight or add a
font, edit `FONTS` in that script and run:

```bash
npm run fonts
```

- The `.woff2` files are the same files Google serves for each subset (latin,
  latin-ext, cyrillic, cyrillic-ext, greek, vietnamese).
- `fonts.ts` loads the Latin files with `next/font/local`, so they are hashed
  and preloaded like before.
- `fonts.css` declares the other subsets, Arial fallbacks adjusted to each
  font's metrics (the values `next/font` generated), and the `--font-jetbrains`,
  `--font-plex-mono` and `--font-plex-sans` variables used by `tailwind.config.ts`
  and `globals.css`.
